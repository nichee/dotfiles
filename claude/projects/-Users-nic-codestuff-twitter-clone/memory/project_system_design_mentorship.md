Building a Twitter clone as part of a system design mentorship program. The goal is to learn horizontal scaling by starting with a naive implementation and evolving it.

**Why:** Learning exercise — the point is to feel the pain of naive approaches and then fix them with proper system design (fan-out strategies, sharding, replicas, CDN, etc.).

**How to apply:** Always start with the simple/naive approach first. Don't optimize prematurely — the learning comes from hitting the wall and then solving it. Future phases will add push-based fan-out, celebrity pull model, sharding, read replicas, S3 for images.
